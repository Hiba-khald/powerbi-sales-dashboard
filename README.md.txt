# 📊 Sales Performance Dashboard (Power BI)

## 📌 Project Overview

This project is an interactive dashboard built using Microsoft Power BI to analyze sales performance across regions, products, and time.

## 🎯 Objectives

* Analyze total sales and profit
* Identify top-performing regions
* Track sales trends over time
* Detect loss-making products

## 🛠️ Tools Used

* Microsoft Power BI
* Excel (Dataset)
* DAX (Data Analysis Expressions)

## 📊 Key Features

* KPI Cards (Sales, Profit, Orders, Profit Margin)
* Sales by Region visualization
* Time-based sales trend analysis
* Interactive filters (Region, Product Category)
* Clean and professional dashboard design

![Dashboard](dashboard.png)

## 🚀 Insights

* The West region shows the highest sales performance
* Sales trends indicate seasonal variations
* Some products generate losses, suggesting optimization opportunities
